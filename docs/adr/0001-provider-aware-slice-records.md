# Choose the canonical Slice provider per Cake

A Cake remains a Trello card and names an optional GitHub Repository. Repository-backed Cakes keep canonical Slices as GitHub issues; Trello-only Cakes keep canonical Slices as Trello cards. Plate is only the current-WIP view, so an active GitHub Slice receives a reciprocal Trello Plate Projection, while every Cake maintains an exhaustive derived Slice Index. This trades a single global Trello registry for better proximity to delivery work without allowing two canonical records or hiding inactive Slices.
