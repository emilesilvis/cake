# Choose the canonical Slice provider per Cake

A Cake remains a Trello card and names an optional GitHub Repository. Repository-backed Cakes keep canonical Slices as GitHub issues; Trello-only Cakes keep canonical Slices as Trello cards. Plate is only the current-WIP view, so an active GitHub Slice receives a reciprocal Trello Plate Projection. Cake derives exhaustive Slice history internally while each Cake card shows its Current or Next Slice and every other Slice available to eat. This trades a single global Trello registry for better proximity to delivery work without allowing two canonical records or hiding viable inactive Slices.
